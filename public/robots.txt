# Content Signals separate ACCESS (can you fetch this?) from USE (what may you
# do with it once fetched). That's why the crawlers below are allowed while
# ai-train is no — it isn't a contradiction, it's the whole point of the spec.
# See https://contentsignals.org and Cloudflare's documentation.
#
#   search=yes     index and rank us, link back to the source
#   ai-input=yes   use our pages to answer a question now (RAG, grounding,
#                  overviews) — we want to be the answer, with a citation
#   ai-train=no    do not bake this content into model weights
#
# IMPORTANT — Cloudflare Edge Note:
# If Cloudflare's "Managed robots.txt / AI Crawl Control" is enabled in the
# dashboard, Cloudflare prepends its own User-agent blocks (e.g. Disallow / for
# GPTBot, ClaudeBot, Google-Extended, Baiduspider) BEFORE this file. Trailing
# Allow rules do NOT reliably override prepended Disallow rules across crawlers.
# Keep Cloudflare Dashboard -> Security -> Bots / AI Crawl Control aligned with
# this file (disable managed robots.txt prepend if using Content-Signal Allow,
# or explicitly block training-only bots there and remove overlapping entries).
